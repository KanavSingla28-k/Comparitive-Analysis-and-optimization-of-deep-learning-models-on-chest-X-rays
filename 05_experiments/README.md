# Experiment workspace

Prepared subfolders: `configs/`, `logs/`, and `checkpoints/`.

Use versioned experiment identifiers and record the model, seed, protocol, data split, training exposure, checkpoint rule, duration, memory, and completion status for each future run.

Existing pilot configurations, logs, and checkpoints are retained in the dated archive. Do not mix changed settings with the pilot comparison under a single experiment ID.

No runs are launched by this preparation step.
